# Fingerings

Selected printed markings from Leopold Godowsky's 1923 Art Publication Society edition of Rachmaninoff, Op. 3 No. 2: [scan](https://s9.imslp.org/files/imglnks/usimg/7/75/IMSLP11125-Godowsky_APS_47_Rachmaninoff-Prelude_Op.3_No.2.pdf), [catalogue](https://imslp.org/wiki/Morceaux_de_fantaisie,_Op.3_(Rachmaninoff,_Sergei)). The catalogue lists this edition as public domain.

304 markings from PDF pages 6–8, covering selected notes in measures 14–41. Printed and MusicXML measure numbers agree. Notes are matched by measure, staff, pitch and offset; duplicate voices receive the same marking. Eight malformed empty positioning tags were removed so the download is valid XML. No notes or timing are changed.

Unmarked patterns are not filled in. Ambiguous alternatives/substitutions are omitted: LH m14 beats 2–4; RH m16 and m20 beat 4; RH m17 beats 2–3; LH m26 beat 1; RH m29 beat 4; RH m30. These are editorial fingerings, not a hand-size-specific arrangement.

Regenerate or verify the bundled MXL:

```sh
python3 scripts/annotate-score.py
python3 scripts/annotate-score.py --check
```

The data records checksums for both the original XML and the cleaned XML, excluding the inserted fingerings and source credit. The script accepts only these checked versions. The app's local fingering and hand edits do not alter this file.
